BMI Calculator
Description

This is a simple BMI (Body Mass Index) Calculator developed using Python as Task 2 of my Python Programming Internship.

The program takes weight in kilograms and height in feet as input. It automatically converts height into meters, calculates BMI, and displays the BMI category.

Features

Weight input in kilograms

Height input in feet

Automatic conversion from feet to meters

BMI calculation

BMI category display

Technologies Used

- Python

How to Run

Install Python.

Open the project folder in the terminal.

Run python bmi_calculator.py.

Enter your weight and height.

BMI Formula

BMI = Weight (kg) / Height (m)²

BMI Categories

Underweight

Normal Weight

Overweight

Obese
