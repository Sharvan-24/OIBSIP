
# Random Password Generator

## Description
This project is a Python-based Random Password Generator developed as Task 3 of my Python Programming Internship at OASIS INFOBYTE.

It generates random passwords based on user-defined length and character types, including uppercase letters, lowercase letters, numbers, and symbols.

## Features
- Custom password length (minimum 8 characters)
- Uppercase and lowercase letters
- Numbers and symbols
- Selection of multiple character types
- Input validation
- Generate multiple passwords without restarting

## Technologies Used
- Python
- random module
- string module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run the following command:

   `python password_generator.py`

5. Enter the password length and select character types.
